# Kapital 프로젝트 비전

## 한 줄 정의

**"일반인도 쉽게 사용할 수 있는 진정한 복식부기 개인 재무관리 앱"**

## 대상 사용자

- 자신의 재무 상태를 정확하게 파악하고 싶은 개인
- 기존 가계부 앱의 단순한 수입/지출 기록에 만족하지 못하는 사용자
- 복식부기 회계의 장점을 알지만 복잡한 회계 소프트웨어는 부담스러운 사용자
- 크로스 플랫폼(웹, iOS, Android)에서 동기화된 재무 관리를 원하는 사용자

## 해결하는 문제

1. **기존 가계부 앱의 한계**: 단순 수입/지출 기록으로는 정확한 재무 상태 파악 불가
2. **회계 소프트웨어의 복잡성**: 전문 회계 지식 없이는 사용하기 어려움
3. **플랫폼 파편화**: 여러 기기에서 일관된 재무 데이터 접근 어려움
4. **재무제표 부재**: 자산/부채 현황, 현금흐름을 한눈에 파악하기 어려움

## 핵심 가치 (3개)

### 1. 정확성 (Accuracy)

- 복식부기 원칙으로 모든 거래가 균형을 이룸
- 차변 = 대변, 항상 검증 가능한 데이터

### 2. 단순함 (Simplicity)

- 복잡한 회계 용어 대신 일상 언어 사용
- 일반적인 거래는 3탭 이내로 입력 완료

### 3. 통찰력 (Insight)

- 자동 생성되는 재무상태표, 손익계산서, 현금흐름표
- 시각적 차트로 재무 건강 상태 즉시 파악

## 핵심 기능 (MVP)

### Phase 1: 기본 기능 ✅

- [x] 계정 관리 (자산, 부채, 자본, 수익, 비용)
- [x] 거래 입력 (복식부기 분개)
- [x] 계정별 거래 내역 조회
- [x] 기본 재무제표 (재무상태표, 손익계산서)

### Phase 2: 사용성 개선 ✅

- [x] 대시보드 (요약 뷰)
- [x] 예산 관리
- [x] 반복 거래
- [x] 거래 편집/삭제

### Phase 3: 확장 기능 (진행 중)

- [ ] 모바일 앱 완성

- [ ] 투자 자산 추적
- [ ] 가족 공유

## 🚫 목표 NOT (명시적으로 하지 않을 것)

다음 기능들은 **의도적으로 제외**합니다:

- ❌ **비즈니스/기업용 회계**: 개인 재무 관리에만 집중
- ❌ **세금 신고 기능**: 세무 소프트웨어 영역
- ❌ **자동 투자 추천**: 로보어드바이저 영역
- ❌ **소셜 기능**: 재무 정보 공유/비교
- ❌ **게이미피케이션**: 뱃지, 랭킹 등 게임 요소
- ❌ **광고 기반 모델**: 사용자 데이터 수익화 없음
- ❌ **복잡한 다중 통화**: 기본 환율 변환만 지원

## 기술 원칙

1. **타입 안전성 우선**: TypeScript strict mode로 런타임 오류 최소화
2. **오프라인 우선**: 네트워크 없이도 기본 기능 사용 가능
3. **프라이버시 중심**: 민감한 재무 데이터 암호화, 최소한의 데이터 수집
4. **점진적 복잡성**: 기본 사용은 단순하게, 고급 기능은 선택적으로
