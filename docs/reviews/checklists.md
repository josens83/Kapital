# 워크플로우 체크리스트 모음

> 각 상황별로 사용할 수 있는 체크리스트 모음입니다.

## 1. 배포 전 체크리스트

```
□ npm run verify 통과 (typecheck + lint + build)
□ 환경 변수 모두 설정됨
  □ NEXT_PUBLIC_SUPABASE_URL
  □ NEXT_PUBLIC_SUPABASE_ANON_KEY
  □ STRIPE_SECRET_KEY (프로덕션)
  □ STRIPE_WEBHOOK_SECRET (프로덕션)
□ Supabase 스키마 변경 시 migration 적용됨
□ Health Check (/api/health) 정상 응답
□ 모바일 앱 영향도 확인 (공유 패키지 변경 시)
□ README 또는 CHANGELOG 업데이트 (주요 변경 시)
```

## 2. 새 기능 시작 전 체크리스트

```
□ VISION.md 확인: 프로젝트 비전과 일치하는가?
□ "목표 NOT" 목록 확인: 해당하지 않는가?
□ 핵심 가치 확인: 정확성, 단순함, 통찰력 중 하나 이상 강화하는가?

□ 사용자 스토리 작성 가능한가?
  "As a [사용자], I want [기능], so that [가치]"

□ MVP 범위 정의됨
□ 성공 기준 명확함
□ 기술 의존성 파악됨
  □ 새 라이브러리 필요?
  □ DB 스키마 변경 필요?
  □ API 변경 필요?
```

## 3. 코드 리뷰 체크리스트

```
□ 타입 안전성
  □ any 타입 사용 최소화
  □ null/undefined 적절히 처리됨
  □ 배열 인덱스 접근 시 안전한 처리

□ 보안
  □ 사용자 입력 검증됨
  □ API 키 하드코딩 없음
  □ SQL 인젝션 방지 (RLS 활용)

□ 성능
  □ 불필요한 리렌더링 없음
  □ 대용량 데이터 페이지네이션 적용
  □ 이미지 최적화 (next/image)

□ 코드 품질
  □ 함수/변수명 명확함
  □ 중복 코드 최소화
  □ 적절한 에러 처리
```

```
□ 브랜치 이름 규칙 준수: feature/, fix/, chore/

□ 스크린샷/GIF 첨부 (UI 변경 시)

□ npm run verify 통과
```

## 6. 주간 점검 체크리스트

```
□ 이번 주 완료 작업 기록
□ 비전 정렬 확인: 모든 작업이 VISION.md와 일치?
□ 다음 주 우선순위 3개 선정
□ WIP 현황 확인 (진행 중 작업 3개 이하?)
□ 막힌 점/기술 부채 기록
```

## 7. 월간 점검 체크리스트

```
□ 이번 달 완료 작업 요약
□ 주요 지표 확인 (커밋 수, 해결 이슈 등)
□ VISION.md 재검토: 여전히 유효한가?
□ "목표 NOT" 목록 재검토
□ ADR 검토: 재고할 결정 있는가?
□ 백로그 정리: 삭제/우선순위 변경
□ 기술 부채 현황 파악
□ 다음 달 주요 목표 3개 설정
```

## 8. AI 세션 관리 체크리스트

```
세션 시작 시:
□ CLAUDE.md 최신 상태 확인
□ 이번 세션의 목표 명확히 정의
□ 필요한 파일 경로 파악

세션 중:
□ 1 태스크 = 1 세션 원칙 준수
□ 구체적인 프롬프트 사용 (파일 경로 명시)

세션 종료 시:
□ 변경 사항 커밋
□ 세션 노트 작성 (docs/session-notes/)
□ CLAUDE.md 업데이트 필요 여부 확인
```

## 빠른 참조: 문제별 해결

| 문제               | 즉시 해결                                 |
| ------------------ | ----------------------------------------- |
| TypeScript 오류    | `npm run typecheck` 후 오류 메시지 확인   |
| 린트 오류          | `npm run lint` 후 `npm run lint -- --fix` |
| 빌드 실패          | 캐시 삭제: `rm -rf apps/web/.next`        |
| Supabase 연결 오류 | 환경 변수 확인, `/api/health` 응답 확인   |
| 배포 후 503 오류   | Health Check 실패, 로그 확인              |
| 모바일 빌드 오류   | `npx expo start --clear`                  |
| Pre-commit 훅 실패 | `npm run verify` 로 원인 파악             |
